A spend and limit firewall for autonomous agents. It approves or blocks an action before it happens — daily budget, per-call cap, rate, writes, transfers and sessions — and a batch either applies completely or not at all.

Free preflight — no wallet

Any agent can ask whether an amount fits the budget before paying. No account, no token:

curl -s "https://zealous-unburned-tameness.ngrok-free.dev/v1/check?budget=50&spent=12.4&amount=0.05"
# {"allow": true, "remaining_before": 37.6, "remaining_after": 37.55, "price_usdc": 0}

curl -s "https://zealous-unburned-tameness.ngrok-free.dev/v1/savings?actions=30"
# 390 vs 4,170 tokens · 10.69x
